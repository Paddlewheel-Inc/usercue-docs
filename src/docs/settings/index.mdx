Settings is `/admin/settings`. The link shows in the sidebar only if you can open at least one tab. UserCue hides tabs you cannot use, and if you open the URL of a hidden tab you are sent to one you can.

## Tabs

| Tab | Permission | What it changes |
| --- | --- | --- |
| [General](/settings/general) | Workspace settings | Guest posting, the changelog switches, assignment, triage tools, and the vote limit |
| Workflow | Workspace settings | Name, color, and icon for each status. See [Statuses](/workspace/statuses) |
| Branding | Manage branding | Site name and description, logo, browser icon, link preview image, and the workspace color palette |
| [Tags](/boards/tags) | Manage posts, or Workspace settings | The tag list, and whether customers can tag |
| [Notifications](/settings/notifications) | Workspace settings | Outgoing email (Resend or SMTP), voter alerts, the weekly digest, and Slack, Discord, and Teams |
| Integrations | Workspace settings | [Webhooks](/integrations/webhooks), [email in](/integrations/email-in), [AI assist](/integrations/ai), the [embed](/integrations/embeds) snippets, and [import](/integrations/import) |
| API keys | Dashboard | Your keys for the [REST API](/api). Owners can also revoke other people's keys |
| [Authentication](/oauth) | Workspace settings | GitHub, Discord, and Google sign-in |
| [Team](/settings/staff) | Manage staff | Staff invites and removing staff |
| [Users](/settings/users) | Manage users | Registered accounts: role, suspend, delete |
| [Roles](/settings/roles) | Manage roles | Role names, icons, and permissions |
| [Audit log](/settings/audit-log) | Workspace settings | Who changed what, for the last 400 days |

Owner can open all of them. The default Staff role cannot open most. Give Staff extra permissions on the Roles tab if they should.

## Where did that setting go?

Settings are grouped by what they do, not by when they were added. If you are looking for something:

| You want to | Go to |
| --- | --- |
| Set up invite or digest email | Notifications, Email delivery |
| Post new suggestions to Slack, Discord, or Teams | Notifications, Chat channels |
| Send events to your own server | Integrations, Webhooks |
| Turn triage scoring and notes off | General, Triage tools |
| Limit how many votes one person has | General, Voting |
| Change the accent color | Branding, Workspace palette |
| See who changed a setting | Audit log |
| Invite a teammate | Team |

## Permissions rules worth knowing

- Someone with only Manage posts can open Settings, but sees only Tags. Someone with only Manage staff sees only Team.
- Changing a user's role needs both Manage users and Manage roles. A role can only grant permissions held by the person creating or editing it. Only an Owner with the full permission set can assign the Owner role. These rules also apply through the REST API.
- Any staff member with Dashboard can create API keys. Each key can only use permissions its owner holds. Only the key's owner can edit its permissions.
- Almost everything in Settings applies to the whole workspace, including the public board. The exceptions are saved views and email preferences, which belong to each person.
